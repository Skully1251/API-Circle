API Circle — Low-Level Design (LLD)

Implementation-ready technical blueprint. Covers the complete PostgreSQL DDL, Express.js middleware pipeline, atomic Redis Token Bucket Lua script, RabbitMQ RPC key validation, Kafka telemetry event streams, and CI/CD pipelines.

1. Service-Level Design & Component Boundaries

API Circle follows the Database-per-Service pattern using logical schemas in PostgreSQL. Each Node.js / Express microservice owns its domain data, enforces business rules, and communicates via REST or messaging:

Microservice Internal Modules Primary APIs & Interfaces Storage & Messaging
api-gateway (Port 3000) Express App, AuthMiddleware, RateLimitMiddleware, QuotaMiddleware, ProxyMiddleware, TelemetryMiddleware
  • /{api_slug}/{version}/** (Consumer API invocations)
  • Extracts x-api-circle-key or Bearer credentials
  • Streams upstream response directly to client
  • Redis 7 (Metadata & Lua state)
  • Kafka Producer: api.usage.events
auth-service (Port 3001) AuthRouter, UserController, RoleRepository, TokenService, PasswordHasher
  • POST /api/v1/auth/register, /login, /refresh
  • POST /api/v1/auth/verify-email, /reset-password
  • Issues signed RS256 / HS256 JWTs with RBAC claims
  • PostgreSQL (auth schema)
  • Redis (Token blacklist: auth:blacklist:*)
user-service (Port 3002) ProfileController, OrgController, MemberRepository, RabbitMqClient
  • GET /users/me, PUT /users/me/profile
  • POST /api/v1/organizations, /members
  • Validates API keys via RabbitMQ RPC client (api-key.validate)
  • PostgreSQL (users schema)
  • RabbitMQ RPC Producer: api-key.validate
api-catalog-service (Port 3004) ApiController, VersionController, EndpointRegistry, CategoryService
  • GET/POST /api/v1/apis, /{id}/versions
  • GET /api/v1/marketplace/categories
  • Stores encrypted provider secrets (AES-256-GCM)
  • PostgreSQL (catalog schema)
  • Redis (Route cache: catalog:route:*)
subscription-service (Port 3007) PlanController, SubscriptionManager, QuotaEvaluator
  • GET /api/v1/apis/{apiId}/plans
  • POST /api/v1/subscriptions, /cancel
  • Manages consumer tier quotas and billing cycles
  • PostgreSQL (subscriptions schema)
  • Redis (Cache: sub:consumer:*:api:*)
api-key-service (Port 3008) KeyGenerator, KeyHasher, KeyValidatorConsumer, AuditLogger
  • POST /api-keys (Issues dual-token keys)
  • RabbitMQ Consumer on api-key.validate (RPC responder)
  • Publishes immediate key revocations to Redis
  • PostgreSQL (api_keys schema)
  • Redis (Key hash cache: apikey:hash:*)
  • RabbitMQ RPC Consumer: api-key.validate
notification-service (Port 3006) TemplateEngine, EmailTransporter, TaskConsumer, RetryManager
  • POST /api/v1/notifications
  • Consumes RabbitMQ task queue notification.dispatch
  • Exponential backoff retry with Dead-Letter Exchange (DLX)
  • PostgreSQL (notifications schema)
  • RabbitMQ Worker: notification.dispatch
analytics-service (Port 3005) KafkaBatchConsumer, MetricAggregator, ReportController
  • Consumes Kafka topic api.usage.events in micro-batches
  • GET /api/v1/analytics/apis/{apiId}/usage
  • Computes latency percentiles (p50, p95, p99) and status error rates
  • PostgreSQL (analytics) / Redis rollups
  • Kafka Consumer: api.usage.events

2. Database Design & Production PostgreSQL DDL

PostgreSQL 16 serves as the single source of truth. Each service operates in its own logical schema. Primary keys use UUIDv4 (uuid_generate_v4()) and cross-service linkages use UUIDs without foreign keys to maintain autonomous deployability.

5. Core Architectural Sequence Workflows

5.1 RabbitMQ Inter-Service RPC API Key Validation

Demonstrates the decoupled, resilient RPC validation pattern implemented between user-service and api-key-service via RabbitMQ:

sequenceDiagram autonumber actor Client as Consumer App participant US as user-service (Port 3002) participant RMQ as RabbitMQ Broker (Queue: api-key.validate) participant KS as api-key-service (Port 3008) participant Redis as Redis (apikey:hash:*) Client->>US: GET /users/me (Header: x-api-key) US->>US: Generate correlationId (UUIDv4) + create ephemeral replyQueue US->>RMQ: sendToQueue('api-key.validate', { apiKey }, { replyTo, correlationId }) RMQ->>KS: Consume 'api-key.validate' message KS->>KS: SHA-256(apiKey) KS->>Redis: GET apikey:hash:{hash} Redis-->>KS: Cached User Context ({ id, email, name }) KS->>RMQ: sendToQueue(replyTo, { valid: true, user }, { correlationId }) RMQ-->>US: Consume response on ephemeral replyQueue US->>US: Match correlationId and resolve Promise US-->>Client: 200 OK ({ user, authenticatedBy: 'api-key-service via RabbitMQ' })

6. Gateway Express Pipeline & Proxy Implementation

The dedicated api-gateway service is built on Node.js 22 and Express 4.x. It executes a lean middleware stack designed for minimal overhead:

gateway-server.js Node.js / Express 
'use strict';

const express = require('express');
const crypto = require('crypto');
const { createProxyMiddleware } = require('http-proxy-middleware');
const Redis = require('ioredis');
const { Kafka } = require('kafkajs');

const app = express();
const PORT = process.env.PORT || 3000;
const redis = new Redis(process.env.REDIS_URL || 'redis://redis:6379');

// Kafka Producer Setup
const kafka = new Kafka({ clientId: 'api-gateway', brokers: (process.env.KAFKA_BROKERS || 'kafka:9092').split(',') });
const producer = kafka.producer();
producer.connect().catch(err => console.error('Kafka connection error:', err));

// 1. Correlation ID Middleware
app.use((req, res, next) => {
  req.correlationId = req.get('x-correlation-id') || crypto.randomUUID();
  res.set('x-correlation-id', req.correlationId);
  req.startTime = Date.now();
  next();
});

// 2. Fast-Path API Key Authentication Middleware
app.use(async (req, res, next) => {
  const rawKey = req.get('x-api-circle-key') || req.get('x-api-key');
  if (!rawKey) {
    return res.status(401).json({ error: 'API key is required in x-api-circle-key header' });
  }

  const keyHash = crypto.createHash('sha256').update(rawKey).digest('hex');
  const cachedMeta = await redis.get(`apikey:hash:${keyHash}`);
  
  if (!cachedMeta) {
    return res.status(401).json({ error: 'Invalid or revoked API key' });
  }

  req.consumer = JSON.parse(cachedMeta); // { id, consumerId, subscriptionId, apiId, plan }
  next();
});

// 3. Distributed Redis Rate Limiting Middleware
app.use(async (req, res, next) => {
  const subId = req.consumer.subscriptionId;
  const rate = req.consumer.plan.rateLimitPerSec || 20;
  const burst = req.consumer.plan.rateLimitBurst || 40;
  const now = Math.floor(Date.now() / 1000);

  try {
    // Call preloaded Token Bucket Lua Script
    const result = await redis.evalsha(req.app.locals.tokenBucketSha, 2, `ratelimit:tb:${subId}`, `quota:monthly:${subId}`, rate, burst, now, 1, req.consumer.plan.monthlyQuota || 0);
    const [allowed, remaining, resetAfter, quotaUsed] = result;

    res.set('X-RateLimit-Limit', rate);
    res.set('X-RateLimit-Remaining', remaining);
    res.set('X-RateLimit-Reset', resetAfter);

    if (allowed === -1) {
      return res.status(403).json({ error: 'Monthly subscription quota exhausted' });
    }
    if (allowed === 0) {
      res.set('Retry-After', resetAfter);
      return res.status(429).json({ error: 'Rate limit exceeded. Please throttle requests.' });
    }

    next();
  } catch (err) {
    console.error('Rate limit error:', err.message);
    next(); // Fail open if Redis rate limit check errors
  }
});

// 4. Dynamic Provider Reverse Proxy
app.use('/:apiSlug/:version', (req, res, next) => {
  const { apiSlug, version } = req.params;
  
  // Resolve target route from Redis cache
  redis.get(`catalog:route:${apiSlug}:${version}`).then(routeJson => {
    if (!routeJson) {
      return res.status(404).json({ error: `API route /${apiSlug}/${version} not found or inactive` });
    }
    const route = JSON.parse(routeJson); // { targetBaseUrl, authType, secret }

    createProxyMiddleware({
      target: route.targetBaseUrl,
      changeOrigin: true,
      pathRewrite: { [`^/${apiSlug}/${version}`]: '' },
      onProxyReq: (proxyReq) => {
        // Inject Provider Upstream Credentials
        if (route.authType === 'bearer') {
          proxyReq.setHeader('Authorization', `Bearer ${route.secret}`);
        } else if (route.authType === 'api_key') {
          proxyReq.setHeader('x-provider-key', route.secret);
        }
      },
      onProxyRes: () => {
        // Asynchronously emit usage metric to Kafka
        const duration = Date.now() - req.startTime;
        producer.send({
          topic: 'api.usage.events',
          messages: [{
            key: req.consumer.consumerId,
            value: JSON.stringify({
              correlationId: req.correlationId,
              consumerId: req.consumer.consumerId,
              subscriptionId: req.consumer.subscriptionId,
              apiSlug,
              version,
              statusCode: res.statusCode,
              durationMs: duration,
              timestamp: new Date().toISOString()
            })
          }]
        }).catch(e => console.error('Kafka emit error:', e.message));
      }
    })(req, res, next);
  }).catch(next);
});

app.listen(PORT, () => console.log(`API Circle Gateway listening on port ${PORT}`));

7. Redis Data Structures & Token Bucket Lua Script

Key Pattern Data Type TTL Purpose
apikey:hash:{sha256} String (JSON) 300s (5 min) Hot cache of consumer ID, subscription ID, plan rates, and active status.
catalog:route:{slug}:{ver} String (JSON) 600s (10 min) Provider backend URL, auth type, and decrypted upstream credentials.
ratelimit:tb:{subId} Hash 60s Token Bucket state: fields tokens (float) and last_updated (seconds).
quota:monthly:{subId} String (Integer) 35 days Atomic monthly request counter for quota checks.
auth:blacklist:{tokenHash} String JWT lifetime Blacklisted refresh tokens and revoked access tokens.

Production Atomic Token Bucket Lua Script

token_bucket.lua Redis Lua 
-- KEYS[1] = ratelimit:tb:{subscriptionId}
-- KEYS[2] = quota:monthly:{subscriptionId}
-- ARGV[1] = rate (tokens/sec)
-- ARGV[2] = capacity (max burst tokens)
-- ARGV[3] = now (epoch seconds)
-- ARGV[4] = requested (usually 1)
-- ARGV[5] = quota_limit (0 = unlimited)

local rate_key    = KEYS[1]
local quota_key   = KEYS[2]
local rate        = tonumber(ARGV[1])
local capacity    = tonumber(ARGV[2])
local now         = tonumber(ARGV[3])
local requested   = tonumber(ARGV[4])
local quota_limit = tonumber(ARGV[5])

-- 1. Check Monthly Quota
if quota_limit > 0 then
    local current_quota = tonumber(redis.call('get', quota_key) or "0")
    if current_quota + requested > quota_limit then
        return {-1, 0, 0, current_quota} -- Quota Exceeded Code
    end
end

-- 2. Fetch or initialize Token Bucket
local data = redis.call('hmget', rate_key, 'tokens', 'last_updated')
local tokens = tonumber(data[1])
local last_updated = tonumber(data[2])

if tokens == nil then
    tokens = capacity
    last_updated = now
else
    local delta = math.max(0, now - last_updated)
    tokens = math.min(capacity, tokens + delta * rate)
    last_updated = now
end

-- 3. Evaluate Rate Limit
if tokens >= requested then
    tokens = tokens - requested
    redis.call('hmset', rate_key, 'tokens', tokens, 'last_updated', last_updated)
    redis.call('expire', rate_key, 60)
    
    local quota_used = redis.call('incrby', quota_key, requested)
    redis.call('expire', quota_key, 3024000) -- 35 days TTL
    
    return {1, math.floor(tokens), math.ceil((capacity - tokens) / rate), quota_used}
else
    local retry_after = math.ceil((requested - tokens) / rate)
    return {0, 0, retry_after, 0}
end

9. Security, Hashing & Cryptographic Utilities

SHA-256 API Key Verification

Plaintext keys are hashed before lookup or persistence:

const crypto = require('crypto');

function hashApiKey(rawKey) {
  return crypto.createHash('sha256')
               .update(rawKey)
               .digest('hex');
}

AES-256-GCM Provider Secret Encryption

Protects upstream provider credentials stored in PostgreSQL:

function encryptSecret(plaintext, key) {
  const iv = crypto.randomBytes(12);
  const cipher = crypto.createCipheriv('aes-256-gcm', key, iv);
  const encrypted = Buffer.concat([cipher.update(plaintext, 'utf8'), cipher.final()]);
  const tag = cipher.getAuthTag();
  return Buffer.concat([iv, tag, encrypted]).toString('base64');
}
